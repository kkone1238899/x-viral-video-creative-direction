### AI 短视频工业化生产 5 步法（@Ox_Shinji）

**核心提炼**
- 解决什么问题：AI 味主要不在主体而在环境层——跨镜头漂移的图形、静止镜头下移动的广告牌、走位穿帮；观众先读环境层，再决定是"电视质感"还是"AI 垃圾"。
- 核心用法（5 步）：1) 找格式不找创意：不看爆款绝对播放量，找"平时 2 万播放的号突然出 60 万"的离群值；扔掉话题，只提取注意力机制骨架（熟悉物体立即出现→一处细节不对劲→观众等它打开→每次揭示升级→最后一帧解释）；2) 给导演 agent 下 brief：把格式骨架+主体交出去拿回分镜级计划，像带小剧组一样分工（专管 reels / 跨镜头风格一致 / 本地化）；3) 让模型赛跑：同一 prompt 在 100+ 模型上跑，用眼看结果选胜者而不看测评；广播级镜头选能稳住人物面孔/服装/世界的模型；4) 搭建"框"而非主体：倒计时图形跨镜头连续不重置、品牌标识固定同一位置、剪辑遵循观众已知语法——主体是便宜的一半，语境是贵的一半；5) 发布即测量：每条按格式打标签，优先看完播率（日常 30% vs 某结构稳定 40%+），数据回流第 1 步形成闭环。
- 什么时候用 / 常见坑：做 AI 短视频账号/内容矩阵的内容策略与工业化生产设计时；开工前定一条绝不打破的视觉铁律（一个镜头规格、一种调色、一段逐字复制到每个镜头的角色描述）——一致性碾压聪明；不要把原创等同于从零开始，短视频注意力运行在已知机制上（变形/升级/倒计时/对比/反转）。

**适用场景**：AI 短视频账号、内容矩阵的内容策略与工业化生产流程设计。

**怎么用它搞钱**："AI 账号工业化生产"代做/代运营——按格式矩阵卖内容、把流程卖给公司、流量稳定后接产品植入，一条生产循环三种收费。

### 创意总监第一纪律：剧本先行，视频最后（@BDFrankHoubre）

**核心提炼**
- 解决什么问题：AI 片子多半不是死在模型上，而是死在剧本上——故事本身不成立，换再好的模型也救不回来，只会白白烧掉 credits。
- 核心用法（3 步）：1) 先诊断故事：这个故事本身站得住吗，有没有值得拍的冲突和走向；2) 严格按顺序推进：手写剧本 → 分镜 → 最后才是视频生成，视频是最后一环不是第一环；3) 烧 credits 之前先审故事：故事没过关就别开生成，生成解决不了剧本问题。
- 什么时候用 / 常见坑：开新片、想换模型"碰运气"的时候先用这条自查；坑：别把"换模型"当成改故事的替代品，模型升级掩盖不了故事漏洞。
- 实证：作者 Lost Garden 第 2 集就是按这个顺序做的——先手写剧本，再画分镜，最后才生成视频。

**适用场景**：AI 短片、短剧开工前的创意决策；团队里"模型不行"争论不断时的定盘星。

**怎么用它搞钱**：接片前先收"剧本诊断/故事会"环节的费用——帮客户把故事立住再开生成，既省算力成本，也显得专业。

**来源**：[@BDFrankHoubre](https://x.com/BDFrankHoubre/status/2114041052004810768) · 2026-10-25

### 品牌联名 reaction 视频的创意简报铁律：露出必须明明白白（@dongqingtry）

- 核心用法（3 步）：1) 给视频打两张成绩单：第一张看视频本身——主体是否突然变脸、动作是否顺滑、画面是否闪烁、镜头是否符合描述（可借鉴 VBench 这类多维评测框架的思路，把"画质"和"是否符合输入"分开看）；第二张看观众得到什么——技术与情感要同时过关，清晰画面与好音频只是基础，技术精良只有在故事值得讲时才托得住；2) 发布前过五问：给谁看（说不出一句具体观众，说明选题还没收窄）；看完多得到什么（新观点、情绪、方法或体验，写不出来先别加动效）；哪处细节证明不是空话（可核对的数据、亲历例子、真实过程，否则注明是观点或推测）；每段每镜是否推进（删掉无损的一段就是在占时长）；划走后留下什么（一句话、一个画面或下一步）；3) 两次快速复看：先关声音，只看画面能不能讲清顺序与变化；再不看屏幕，只听解说有没有完整意思；同时检查镜头位置、运动、构图、景别、景深与光线，转场没推进信息或情绪就只是装饰。
- 工作流结论：先写下内容承诺——看完后哪类观众会多懂、感到或做到什么，再让工具做草稿、字幕、画面或剪辑方案，至少比较两个方向，自己决定留什么、删什么、核对哪些事实，只保留让承诺更清楚的部分。
- 什么时候用 / 常见坑：AI 短片、口播、带货视频成片前的审片与终审环节；坑：拿"用了哪个模型"当卖点，除非工具本身就是主题。
- 引用边界：作者引用的两项研究是写作与故事实验，不是短视频实测，只作多样性提醒理解，不当爆款率证据；调查数据为作者引用的第三方调查，转述时已注明是作者引用。
